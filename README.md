# Лабораторна робота №5, варіант №34 — порівняння чисельних методів

Модель: затухаючий гармонічний осцилятор `m x'' + c x' + k x = 0` (аналітичний розв'язок відомий).
Методи: явний Ейлер, симплектичний (напівнеявний) Ейлер, Рунге–Кутта 4-го порядку.
Порівнюються точність, стійкість і час обчислень для різних `dt` та параметрів `m, k, c`.

## Структура
| Файл | Призначення |
|---|---|
| `cpp/physics.hpp` | фізична модель, аналітичний розв'язок, три методи, аналіз стійкості (без SFML) |
| `cpp/experiments.cpp` | серія експериментів, вимірювання часу (`std::chrono`), вивід у CSV |
| `cpp/main.cpp` | SFML-візуалізація (SFML 3): кулі методів + живий графік x(t) (`VertexArray`/`LineStrip`); ↑↓ — k, ←→ — c (змінюють модель і перезапускають), `[` `]` — dt, Space — пауза, R — перезапуск |
| `cpp/make_plots.cpp`, `cpp/svgplot.hpp` | побудова всіх рисунків (SVG) з CSV — чистий C++, без залежностей |
| `cpp/CMakeLists.txt`, `vcpkg.json`, `CMakePresets.json` | збірка (CMake + vcpkg) |
| `data/` | результати запуску (CSV + `log.txt`) |

## Збірка і запуск
Експерименти (потрібен лише компілятор C++17):
```
g++ -O2 -std=c++17 cpp/experiments.cpp -o experiments
./experiments data        # ~40 с, створює CSV у data/
g++ -O2 -std=c++17 cpp/make_plots.cpp -o make_plots
./make_plots data figs_svg   # рисунки у SVG (для Word: rsvg-convert -z 2 fig.svg -o fig.png)
```
SFML-візуалізація (Visual Studio / CMake + vcpkg): відкрити папку `cpp/`, виконати `vcpkg x-update-baseline --add-initial-baseline`,
`Build All`, запустити ціль `SFML_Lab`. Без SFML: `cmake -DBUILD_SFML_DEMO=OFF`.

## Перевірки коректності (з `data/verify.csv`)
* аналітичний розв'язок збігається з РК4 при `dt = 1e-4` до `5.5e-14`;
* цикл інтегрування збігається з матрицею кроку `Mᴺ` до `3e-15`;
* теоретична стійкість (`ρ(M) ≤ 1`) збіглася з експериментом у 39 з 39 випадків.

Стан: `experiments.cpp` і `make_plots.cpp` скомпільовано (g++ 13, `-Wall -Wextra`, без попереджень) і запущено; `main.cpp` не збирався з реальною SFML (її немає в середовищі підготовки); перевірено лише синтаксис проти власної заглушки.
